# 🌦 Gandhinagar Weather Data Analysis

## 📌 Project Overview
This project performs statistical analysis on the last 10 days of weather data for Gandhinagar.

The following parameters are analysed:
- 🌡 Temperature
- 💧 Humidity
- 🌫 AQI (Air Quality Index)

---

## 🧮 Operations Performed

For each parameter:
- ✅ Average Calculation
- ✅ Median Calculation
